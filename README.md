# Daniel Choi — Academic Website

Source for [danielchoi20.github.io](https://danielchoi20.github.io/), an academic portfolio for Donghyun (Daniel) Choi.

## Branches

- `master`: currently published website
- `archive-2020-site`: preserved snapshot of the original 2020 website
- `redesign-2026`: new website under development

## Preview locally

From this directory, run a static server such as:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000/`. The site uses plain HTML and CSS and requires no build step.

## Content

- `index.html` — single-page website with About, Research, Teaching, Leadership & Impact, and Contact sections
- `files/Daniel_Choi_CV.pdf` — downloadable CV
